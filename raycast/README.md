# Zen Garden for Raycast

In Raycast, open **Settings → Extensions → Add Directories** and choose this
folder. Raycast will discover:

- **Unblock a Website** — opens the required reason form
- **Resume Blocking** — ends active exceptions immediately
- **Open Zen Garden** — opens the full app

Build and launch Zen Garden once before using these commands so macOS registers
the `zengarden://` command link.
